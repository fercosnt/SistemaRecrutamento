# v5.0 (M5 — Gestão de Usuários & Perfil RH) — Milestone Audit

**Milestone goal (PROJECT.md / ROADMAP.md):** Implementar de verdade a gestão de contas internas do RH — o feature-debt que o M4 deixou apenas gateado/ocultado (**A14** Gestão de Usuários RH + **A37** Meu Perfil RH) — com **segurança como eixo**: toda escrita privilegiada roda numa Edge Function service_role **authenticate-THEN-authorize** (nunca service_role no client), sobre um `usuarios_rh` com RLS admin-only que **preserva** a policy `auth_admin_le_usuarios_rh` do `custom_access_token_hook`, com LGPD via soft-delete/desativação + trilha de auditoria append-only e guarda anti-lockout server-enforced.
