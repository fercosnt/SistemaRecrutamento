|----------|-------------|
| authenticated RH client → candidaturas UPDATE | untrusted status/etapa write crosses into Postgres; RLS is row-level, NOT a structural invariant |
| DEFINER RPC body (elevated) → base tables | RLS does NOT apply inside a SECURITY DEFINER body — authorization must be explicit in-body |
| Supabase transaction pooler | connections are reused across requests → any session-scoped state leaks |
