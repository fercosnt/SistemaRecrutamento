| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-29-08 | Denial of Service (self-lockout) | anti-lockout hint | mitigate | Client disables Desativar + demote on the last active administrador (derived from rows) with a keyboard-reachable tooltip — BUT the EF/trigger LAST_ADMIN (Phase 28) is the authoritative guard; the hint is UX only and a race falls back to the server toast |
| T-29-09 | Repudiation (dishonest confirm copy) | Resetar-senha AlertDialog | mitigate | Body states only what the EF does (dispatches a reset e-mail; current password stays valid) — does NOT claim the account is locked or the password already changed |
