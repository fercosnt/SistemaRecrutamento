<objective>
Author the two DB-teeth migrations: the race-safe anti-lockout trigger (USR-07) and the atomic mutate+audit RPC(s) (USR-06). The trigger is the only bypass-proof guarantee of >=1 active administrador — it fires even for the service_role EF, and serializes admin-count mutations via pg_advisory_xact_lock to defeat the "two admins demote each other" write-skew. The RPCs guarantee that a row change and its audit row commit together (one transaction) so the mutation and its trail can never diverge.

Purpose: server-enforced anti-lockout that no client or EF path can circumvent, plus atomic auditing that satisfies the mutation half of USR-06.
Output: two migration files (authored only; applied in 28-07).

  early-return if OLD is not an active admin, or if NEW stays an active admin;
  else PERFORM pg_advisory_xact_lock(hashtext('usuarios_rh_admin_guard'));
       SELECT count(*) INTO others FROM usuarios_rh WHERE role='administrador' AND ativo AND deleted_at IS NULL AND id<>OLD.id;
       IF others=0 THEN RAISE EXCEPTION ... USING ERRCODE='P0001'; END IF;
  bound via BEFORE UPDATE OR DELETE trigger (idempotent DO/pg_trigger IF NOT EXISTS).
gerir_usuario_rh_mutacao(p_actor uuid, p_target uuid, p_action text, p_novo_papel text DEFAULT NULL) RETURNS void
  SECURITY DEFINER SET search_path=public: read antes FOR UPDATE (NOT_FOUND -> P0002); UPDATE by action
  (mudar_papel/desativar -> severidade 'critico'; ativar -> 'aviso'); PERFORM log_auditoria(categoria 'usuario').
