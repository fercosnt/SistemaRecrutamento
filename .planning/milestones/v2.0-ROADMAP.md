## Overview

M2 delivered the full RH (recruiter) hiring funnel with AI-assisted evaluation, built on top of the M1 candidate experience. A 6-stage pipeline (`inscricao` → `triagem` → `avaliacao_assincrona` → `entrevista_online` → `entrevista_presencial` → `decisao_final`, plus terminal `aprovado`/`rejeitado`) became the auditable source of truth, with every stage transition recorded in `historico_candidatura` and RLS on 100% of new tables.

On top of the pipeline backbone, M2 shipped: per-role vaga configuration with weighted sliders and option tags; an LGPD-clean inscription form with objective, auditable knockouts; a shared versioned AI prompt library with mandatory cost/token logging and a cost-anomaly alerter; AI triagem (`score_match`) + a side-by-side comparativo with PDF export; structured async evaluation (deterministic Work-Sample/SJT + anti-tampering server-side Big Five with a respectful D-lite devolutiva + a cultural-fit redação scored by AI BARS with **mandatory human review**); AI-companion interview guides (STAR/PEI) + transcript analysis + opt-in CC0 cognitive reasoning marked CONTEXTUAL; an auditable final decision with a mandatory textual justification, an LGPD Art. 20 candidate explanation endpoint, and an EEOC 4/5 bias audit; and a WCAG-AA + tech-debt hardening pass.

**Invariant held throughout:** the system **NEVER auto-rejects on a score** (RNF-07a). AI is always a *recommendation*; a human always makes the decision, and every `decisao_final` carries `por_usuario IS NOT NULL`.

## Milestone Summary

**Decimal / inserted phases:** none in M2. Two phases gained a `-07` gap-closure plan from review (14-07, 15-07).

**Key Decisions:**

- `scores_candidato` as a single generic sink with a `tipo_score` enum that forward-declares all evaluation types — avoids `ALTER TYPE` churn across Phases 12-15.
- Answer-keys live in `*_metadata` / `pergunta_opcao_sjt` with candidato-DENY RLS; candidates read options via `SECURITY DEFINER` RPCs (id+texto only, randomized) — RLS is row-level, not column-level (`reference_select_star_leaks_pii`).
- Hybrid git→DB prompt versioning (git = source of truth, DB = runtime) with idempotent content-hash UPSERT — enables canary/rollback at runtime + audit in git.
- All privileged write Edge Functions use the two-client pattern and **authorize after authenticating** (`reference_ef_authenticate_vs_authorize`) — caught as a CRITICAL IDOR in Phase 10.
- AI is always a recommendation; human review is mandatory for redação (every essay → `pendente_humano`) and required before any score-based advance; **zero auto-rejection by trait/score** (RNF-07a, LGPD-02).
