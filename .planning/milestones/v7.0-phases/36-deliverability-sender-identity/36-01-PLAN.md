## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `Deno.env` → runtime da Edge Function | `NOTIFICACOES_MODO` é configuração externa não confiável; um valor errado decide se um e-mail vai para uma pessoa real |
| `email-config.ts` → API do Resend (P38) | O header `to` construído aqui é o que determina quem recebe; um bug aqui é um envio indevido, não um crash |
| Endereço de candidato (PII) → endereço de terceiro (`resend.dev`) | O `+label` viaja para fora da infra Beauty Smile |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-36-01-01 | Tampering | `resolverModo()` — env `NOTIFICACOES_MODO` malformado ou ausente em dev/CI leva a envio real a candidato | mitigate | Fail-safe: apenas a string exata `producao` (após `trim().toLowerCase()`) habilita produção; qualquer outro valor ⇒ `teste` + `console.warn`. Provado pelos casos 1-2 da suite Deno |
| T-36-01-02 | Information Disclosure | PII do candidato vazada num endereço de terceiro via `+label` do `resend.dev` | mitigate | `+label` é o nome do evento sanitizado para `[a-z_]`; proibido usar `candidatura_id`/e-mail/nome. Caso 4 prova que os 4 labels são só nomes de evento |
| T-36-01-03 | Spoofing | From de produção cair em `onboarding@resend.dev` (domínio do provedor) e ser tratado como phishing | mitigate | `FROM` é `const` congelada e o caso 7 asserta que não contém `resend.dev` |
