Table `public.agendamentos_entrevista` (20260716000001:23-53). Client-writable columns:
  candidatura_id uuid (required), tipo public.tipo_entrevista_avaliacao ('online'|'presencial'), data_hora timestamptz,
  local_ou_link text, status public.status_entrevista (default 'agendada'; values agendada/em_andamento/concluida/
  cancelada/reagendada/nao_compareceu), observacoes_rh text (RH-only), entrevistador text, compareceu boolean (nullable=pending).
TRIGGER-STAMPED — DO NOT send in any insert/update payload: vaga_id, agendado_por, updated_by, updated_at
  (the BEFORE trigger `agendamento_normaliza_vaga_id` overwrites vaga_id; the P33 write-stamp trigger sets the audit cols).
Cancel = UPDATE status='cancelada' (row KEPT — the candidate must see the cancellation via get_meu_agendamento in P35);
  hard removal is a deleted_at set, NOT used by this UI. Reagendar = UPDATE in place, status='reagendada'.
RLS `rh_gerencia_agendamento` (FOR ALL, WR-04 join-through) gates every read/write — no client-side scope needed.

Allowlist read: select the RH-facing columns id, candidatura_id, tipo, data_hora, local_ou_link, status,
  observacoes_rh, entrevistador, compareceu (RH sees observacoes_rh; the candidate path is the separate P35 RPC). Never select('*').

Hub mount point (`HubCandidatoRH.tsx`): the "Entrevista" HubSection is at :357-367. Render AgendamentoBlock as a

  otherwise the block shows HubSection estado="futuro". `:id` route param IS candidaturaId (Pitfall 8).

Service/hook/form patterns: `entrevistaService.ts` (class XServiceError + mapRpcError 42501→FORBIDDEN); `entrevistaKeys`
