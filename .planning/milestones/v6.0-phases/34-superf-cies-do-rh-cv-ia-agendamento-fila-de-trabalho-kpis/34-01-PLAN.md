LIVE baseline (3 keys, preserve VERBATIM after the pg_get_functiondef diff): scope predicate everywhere is
`(v_is_admin OR v.created_by = v_uid) AND (p_vaga_id IS NULL OR v.id = p_vaga_id) AND c.deleted_at IS NULL`.
CTE chain: scoped_hist (PII-safe projection candidatura_id/etapa_de/etapa_para/criado_em/vaga_id — NEVER ator, NEVER any candidatos column) → deltas (LEAD dwell) → median (percentile_cont(0.5) over non-null dwell) → conversion (raw etapa_de→etapa_para counts) → volume (current etapa_atual distribution).

4 NEW keys — signals pinned to live schema (full CTE SQL in 34-RESEARCH.md §"Extending funil_kpis" §1-4):
- time_to_hire: median seconds from candidaturas.data_candidatura (COALESCE created_at) to the scoped_hist row whose etapa_para='aprovado'. Returns a bare bigint seconds (mirrors median_time_per_stage unit) or JSON null. CTE `tth`.
- knockout_rate: `{knockouts, total, taxa}` where knockouts = candidaturas with motivo_rejeicao='knockout_automatico', total = all scoped candidaturas, taxa = round(knockouts::numeric/total,4) with a CASE WHEN total>0 guard. CTE `ko`.
- drop_per_stage: per-stage `{dropped, saidas, taxa}` from scoped_hist — dropped = exits by etapa_para='rejeitado', saidas = all exits (closed cohort), excluding etapa_de IS NULL, the inscricao self-loop (etapa_de = etapa_para), and terminals ('aprovado','rejeitado'). COALESCE to '{}'::jsonb. CTE `drop_flow`.
- no_show_rate: `{no_shows, total, taxa}` from agendamentos_entrevista joined through candidaturas→vagas (same owner scope) — no_shows = compareceu=false, total = compareceu IS NOT NULL (decided only), a.deleted_at IS NULL, CASE WHEN total>0 guard else taxa=null. CTE `ns`.

v_fila_trabalho (34-RESEARCH.md §"Work-Queue" recommended shape): CREATE OR REPLACE VIEW public.v_fila_trabalho WITH (security_invoker = true) — columns candidatura_id, vaga_id, vaga_titulo, candidato_id, candidato_nome, etapa_atual, status, entrou_etapa_em (= greatest(max(h.criado_em), data_candidatura, created_at) grouped per candidatura); WHERE c.deleted_at IS NULL AND c.etapa_atual NOT IN ('aprovado','rejeitado'); GRANT SELECT TO authenticated. Scope is FREE via the inherited rh_le_candidaturas vaga-scoped RLS (base-table security_invoker).
