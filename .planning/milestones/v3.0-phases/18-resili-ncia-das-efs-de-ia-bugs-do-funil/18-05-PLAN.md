Close the RESIL-03 plumbing GAP: extract a shared `extractEfErrorCode(data, error)` helper and wire it into every AI-invoking service so the EF body's `error_code` (notably `AI_UNAVAILABLE`) reaches the thrown `*ServiceError` — and therefore `<AsyncState errorCode>`. This plan generalizes that one partial impl into a shared helper (avoiding per-service drift — the integration-contract lesson) and threads `error_code` through all the AI services.
Output: `src/lib/efErrors.ts` + test; `error_code` surfaced on `DecisaoServiceError` / `AvaliacaoServiceError` / `bigfiveService` error / `TriagemServiceError`.

Shared helper to add (RESEARCH Code Examples — reads BOTH body shapes, degrades safely):
```
async function extractEfErrorCode(data: unknown, error: { context?: Response } | null): Promise<string | undefined> {
  if (data && typeof data === 'object' && 'error_code' in data) {
    return String((data as { error_code?: unknown }).error_code ?? '') || undefined
  }
  try {
    const body = await error?.context?.json?.()
    if (body && typeof body === 'object' && 'error_code' in body) return String((body as { error_code?: unknown }).error_code ?? '') || undefined
  } catch { /* not JSON — generic */ }
  return undefined
}
```
