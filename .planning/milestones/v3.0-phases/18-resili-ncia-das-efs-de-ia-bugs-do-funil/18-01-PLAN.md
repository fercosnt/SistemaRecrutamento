<objective>
Harden the shared AI orchestrator `callAi()` so every AI Edge Function gains a bounded per-call timeout and env-configurable retry attempts, eliminating the live 38–102s hang (achado #1) without rebuilding the existing retry/backoff/breaker/fallback machinery.

Purpose: RESIL-01 — EFs de IA resistem a latência alta e overload transiente da Anthropic. Without it, the Anthropic SDK's default timeout (10min, scaled up to 60min for large max_tokens) lets one overloaded call blow the EF's 150s idle ceiling before the retry loop ever runs.
Output: `_shared/ai-client.ts` with `AI_CALL_TIMEOUT_MS` + `MAX_ATTEMPTS` env config and `{ timeout, maxRetries: 0 }` on both provider calls; extended `ai-client.test.ts` asserting the options reach the provider.
