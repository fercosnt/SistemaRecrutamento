# Phase 18 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope of this phase (RESIL-03 only):** This is a hardening phase, not a feature phase. The *only* UI surface in scope is graceful degradation: extract ONE shared `<AsyncState>` wrapper that generalizes the existing `HubSection` async-state pattern, and adopt it on the AI-backed screens so candidate and RH always see a clear **loading / slow / error / empty / success** state with a standardized **"Tentar novamente"** retry — never a blank screen. No new screens, no new tokens, no layout changes. This contract therefore declares only the tokens that `<AsyncState>` and its adoption touch; it does not re-specify the whole design system (locked by prior phases — see `17-UI-SPEC.md`, `15-UI-SPEC.md`).

---

## States Contract (the core of RESIL-03)

`<AsyncState>` renders exactly ONE of these states in strict priority order. It is a presentational wrapper that maps a TanStack Query result (`{ isLoading | isPending, isError, error, refetch }`) plus an optional emptiness predicate. It composes with the existing glass UI by rendering its surface inside a `<Glass variant="dark" blur="lg" className="rounded-xl p-6">` block (identical idiom to `HubSection`), or rendering bare when the caller already provides the glass shell.

| Priority | State | Driver | What renders | Verbatim PT-BR copy |
|----------|-------|--------|--------------|---------------------|
| 1 | **loading** | `isLoading \|\| isPending` (fast, < slowAfterMs) | `<Skeleton className="h-24 w-full bg-white/5" />` (mirrors `HubSection`) | — (no text) |
| 2 | **slow** | still pending after `slowAfterMs` (default 8000ms) | skeleton + inline `Loader2` spinner + slow-call note | heading: *"Estamos processando com IA…"* · body: *"Isso pode levar até ~30 segundos. Não feche esta tela."* |
| 3 | **error** | `isError` AND error is non-retryable, OR retry exhausted | `AlertTriangle` icon (`text-red-300`) + message + retry button | heading: *"Não foi possível concluir agora."* · body: *"O serviço de IA está sobrecarregado. Tente novamente em instantes."* |
| 4 | **empty** | caller's `isEmpty` predicate is true | centered heading + body, no fabricated data | heading: *"Nada para mostrar ainda"* · body: *"Os dados desta etapa aparecerão aqui quando estiverem disponíveis."* |
| 5 | **success** | none of the above | render `children` | — |

**State-driver rules (binding):**
- `isError`/`isLoading` flags take precedence over `estado`/`isEmpty` (caller maps TanStack Query directly), preserving the `HubSection` convention.
- The **slow** state is a timed escalation of **loading**, not a separate query state — it appears only while still pending past `slowAfterMs`. It must never replace a resolved success/error.
- The error state is shown for any `isError`. When the underlying EF returns the structured contract `{ error_code: 'AI_UNAVAILABLE', retryable: true }` (HTTP 503), the error copy above applies verbatim (sobrecarga). For non-AI/generic errors the wrapper falls back to the same heading with body *"Verifique a conexão e tente novamente."*
- The retry button is present in the **error** state ONLY. It calls the caller-supplied `onRetry` (wraps `refetch()` or re-invoke). No retry button on loading/slow/empty/success.

### Retry affordance (standardized — supersedes the per-screen variants)

| Property | Value |
|----------|-------|
| Component | `GlassButton` (`@/components/ui/glass`) — the existing exemplar in `ConsolidacaoDashboard.tsx:108` |
| Variant | `variant="white" hover` |
| Label | **"Tentar novamente"** (verbatim, no ellipsis) |
| Action | `onRetry()` → `refetch()` / re-invoke EF; while the retried request is pending the button shows `Loader2` spinner + label **"Tentando…"** and is `disabled` (no double-submit) |
| Touch target | `min-h-[44px]` (carry the BigFive/SJT touch-target rule; mobile candidate surfaces) |
| Icon | optional `RotateCcw` (lucide) at 16px to the left of the label; gap 8px |

### Slow-call submit affordance (for the AI-invoking action buttons, not the wrapper)

The existing submit pattern is already correct and becomes the contract — `<AsyncState>` covers *reads*; submit buttons that trigger a slow AI EF keep this inline pattern:
- Spinner: `Loader2 className="w-4 h-4 animate-spin"` + label **"Enviando…"** (BigFive) / **"Processando…"** (generic AI invoke).
- `disabled` while in flight (prevents double-submit — RESIL-03 "nunca tela em branco / nunca dupla submissão").
- For calls expected > ~10s (e.g. Big Five devolutiva ~30s, redação scoring), pair the in-flight button with the `<AsyncState>` **slow** copy in the result region so the user knows the wait is expected.

## Component API (`<AsyncState>`) — Claude's discretion, recommended shape

The exact name/API is Claude's discretion per CONTEXT.md. Recommended contract so checker and executor align:

```tsx
interface AsyncStateProps {
  isLoading?: boolean        // takes precedence (TanStack isLoading|isPending)
  isError?: boolean          // takes precedence over isEmpty
  isEmpty?: boolean          // caller predicate (e.g. !data?.items.length)
  errorCode?: string         // 'AI_UNAVAILABLE' → sobrecarga copy; else generic
  slowAfterMs?: number       // default 8000
  onRetry?: () => void       // shown in error state only
  retrying?: boolean         // drives "Tentando…" + disabled
  glass?: boolean            // wrap in <Glass variant="dark">; default true
  copy?: Partial<AsyncStateCopy> // per-call overrides; defaults are the verbatim table above
  children: ReactNode        // success content
}
```

Copy lives in ONE `COPY` const inside the component (same single-source guarantee as `HubSection`'s `COPY`) so the verbatim strings never drift.

## Spacing Scale

Declared values (multiples of 4) — only those `<AsyncState>` and its adoption touch:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | — (not used by this phase) |
| sm | 8px | gap between retry icon and label; gap-2 inside state blocks |
| md | 16px | wrapper inner padding rhythm |
| lg | 24px | `p-6` glass surface padding (`HubSection` idiom) |
| xl | 48px | `p-12` vertical breathing room for error/empty centered blocks (`ConsolidacaoDashboard` idiom) |

Exceptions: **44px minimum touch target** (`min-h-[44px]`) on the retry button — carried verbatim from the candidate-facing BigFive/SJT touch-target rule; this is a deliberate non-multiple-of-4 accessibility exception, not arbitrary.

## Typography

Carried from the locked glass UI (prior phases) — only the roles `<AsyncState>` renders:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.5 |
| Label / heading-in-block | 16px (`text-base`) | 600 (semibold) | 1.2 |
| Section title (when wrapped) | 20px (`text-xl`) | 600 (semibold) | 1.2 |

Two weights only: regular (400) for body/help text, semibold (600) for headings/labels. State-block headings are `text-base font-semibold text-white`; bodies are `text-sm text-white/70` (the exact `HubSection.EstadoVazio` idiom).

## Color

The funnel glass surfaces are dark-glass; text is white/translucent (passes WCAG AA on `bg-black/30`). Brand tokens are defined in `src/styles/globals.css` and exposed as Tailwind semantic tokens.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | dark glass — `bg-black/30` (`Glass variant="dark"`) | wrapper surface; text `text-white` / `text-white/70` |
| Secondary (30%) | white-translucent — `bg-white/5`, `bg-white/[0.03]`, `border-white/10` | skeletons, inner blocks, dividers |
| Accent (10%) | brand-accent `#35BFAD` (`--accent`) | NOT introduced by this phase — `<AsyncState>` uses no accent fill (neutral by design) |
| Destructive | `#EF4444` → used as `text-red-300` | error-state `AlertTriangle` icon ONLY (never as a fill or a verdict) |

Accent reserved for: **nothing new in this phase.** `<AsyncState>` is intentionally neutral — loading/slow/empty are white-on-dark-glass; error uses a single `text-red-300` icon as a signal, never a red background or border (mirrors `ConsolidacaoDashboard`, which keeps red off the score because it is signal, not verdict). The retry `GlassButton` uses `variant="white"`, not accent.

## Copywriting Contract

All copy is PT-BR, verbatim, single-sourced in the component's `COPY` const.

| Element | Copy |
|---------|------|
| Primary CTA (retry) | **Tentar novamente** |
| Retry in-flight label | **Tentando…** |
| Slow-call heading | **Estamos processando com IA…** |
| Slow-call body | **Isso pode levar até ~30 segundos. Não feche esta tela.** |
| Error heading | **Não foi possível concluir agora.** |
| Error body (AI overload — `error_code: 'AI_UNAVAILABLE'`) | **O serviço de IA está sobrecarregado. Tente novamente em instantes.** |
| Error body (generic / network) | **Verifique a conexão e tente novamente.** |
| Empty state heading | **Nada para mostrar ainda** |
| Empty state body | **Os dados desta etapa aparecerão aqui quando estiverem disponíveis.** |
| Submit in-flight (BigFive) | **Enviando…** |
| Submit in-flight (generic AI invoke) | **Processando…** |
| Toast (optional, transient only) | **Não foi possível enviar agora. Tente novamente.** |

`HubSection`'s existing funnel-relative copy (*"Etapa ainda não iniciada"*, *"Sem dados nesta etapa"*) is preserved as `HubSection`-specific overrides on top of `<AsyncState>` — those strings do not change.

**Destructive actions:** none in this phase. Retry is non-destructive (re-runs a read/invoke). No confirmation dialogs introduced.
