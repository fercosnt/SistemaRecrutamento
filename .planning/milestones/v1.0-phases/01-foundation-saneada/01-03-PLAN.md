**Create `src/components/LoadingDelay.tsx` (per D-04):**
```typescript
import { type ReactNode, useState, useEffect } from 'react'

interface LoadingDelayProps {
  delay?: number
  children: ReactNode
}

export function LoadingDelay({ delay = 200, children }: LoadingDelayProps) {
  const [show, setShow] = useState(false)

  useEffect(() => {
    const timer = setTimeout(() => setShow(true), delay)
    return () => clearTimeout(timer)
  }, [delay])

  return show ? <>{children}</> : null
}
```

**Verification order (CRITICAL per D-06):**

2. Not authenticated OR role is null -> `<Navigate to={'/auth/login?redirect=' + encodeURIComponent(location.pathname + location.search)} replace />`

   - RH trying candidato area: `'Esta area e exclusiva para candidatos'`
4. Correct role -> render `<>{children}</>`

The 200ms delay uses internal `useState(false)` + `useEffect` with `setTimeout`. When `isLoading` becomes false, reset showSpinner to false immediately.

The toast for wrong role must only fire once per redirect (not on every render). Use a ref or ensure Navigate fires immediately so the component unmounts before re-rendering.
