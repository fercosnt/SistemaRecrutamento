# Phase 7 — UI Design Contract

> Visual and interaction contract for **Configuração de Vaga & Tags** — an internal RH/Admin
> (desktop-first) screen. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope (CONTEXT D-02):** only the 3 new M2 blocks — **TemplateVagaSelector**, **PesosSliders**,
> and the **Tag Wizard** (PerguntaWithTagsForm + BulkMarkDialog). The legacy tabs
> (Básicas/Landing/Perguntas/IA) stay visually as-is and are NOT re-specified here.
>
> **Reused shell (CONTEXT D-01):** the Glass + Tabs visual casca from
> `src/components/pages/CriarEditarVagaPage.tsx` (white text on dark glass over a `#00109E`
> background). This contract specifies how the 3 new blocks sit inside that established shell —
> it does NOT introduce a new visual language.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn primitives vendored under `src/components/ui/`; no `components.json` registry) |
| Preset | not applicable — manual Tailwind theme + Beauty Smile Glass design system |
| Component library | radix (shadcn/ui primitives) + custom `Glass` component (`src/components/ui/glass.tsx`) |
| Icon library | lucide-react (project default) |

**Primitives already vendored (reuse, do NOT re-add):** `Slider`, `Dialog`, `Select`,
`Tabs`, `RadioGroup`, `Label`, `Input`, `Form`, `Badge`, `Card`, `Button`, `Switch`,
`Tooltip`, `Sonner` (toasts) — all under `src/components/ui/`.

**Surface convention (CONTEXT code_context + legacy shell):** content sits on
`Glass variant="white"` cards (`bg-white/15 border-white/25`) over the dark `#00109E`
`BackgroundImage`. All text on glass is `text-white` / `text-white/80` / `text-white/60` with
`drop-shadow-sm` for legibility (established pattern, `CriarEditarVagaPage.tsx:299-352`). New
blocks MUST follow this — never place dark-on-dark text on the glass surface.

## Spacing Scale

Declared values (Tailwind 4px base; multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, badge inner padding, slider tick spacing |
| sm | 8px | Compact spacing inside a tag row (tag select ↔ peso input ↔ nota_ia) |
| md | 16px | Default gap between form fields and between sliders |
| lg | 24px | Padding inside Glass cards; gap between the 3 blocks |
| xl | 32px | Gap between the live-sum summary and the slider group |
| 2xl | 48px | Major section breaks (Template block ↔ Pesos block ↔ Tag wizard block) |
| 3xl | 64px | Page-level top/bottom rhythm (inherited from legacy shell) |

Exceptions:
- **Interactive control min-height 44px** for slider thumbs, the "tudo informativa" bulk button,
  and the per-option tag `Select` — desktop-first but keeps comfortable hit targets. 44 is a
  hit-target exception, not a layout token.

## Typography

Sizes drawn from the existing `--text-*` scale (`globals.css:79-85`). Declared set for this
phase — exactly 4 sizes, 2 weights:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (`--text-base`) | regular (400) | 1.5 |
| Label | 14px (`--text-sm`) | semibold (600) | 1.4 |
| Heading (block title) | 20px (`--text-xl`) | semibold (600) | 1.2 |
| Display (page H1) | 28px (`--text-3xl`) | semibold (600) | 1.2 |

Weights restricted to **400 (regular)** and **600 (semibold)** for this phase. Do not introduce
500/700/800 in the new blocks (legacy shell uses `text-3xl` H1 already — match it at 600).

- Numeric peso inputs and the live "Soma: X%" indicator: Body 16px / 400. The **percentage value
  itself** ("100%", "85%") may render semibold (600) for scan-ability — same size, weight bump only.

## Color

The 60/30/10 split below describes the **new blocks on the dark Glass surface**, consistent with
the canonical persona shell (not a light-theme screen).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#00109E` (brand-primary, `--brand-primary`) | Page `BackgroundImage` / dark base |
| Secondary (30%) | `rgba(255,255,255,0.15)` (`Glass variant="white"`) | Cards wrapping each of the 3 blocks; field surfaces |
| Accent (10%) | `#35BFAD` (brand-accent, `--brand-accent`) | See reserved-for list below |
| Destructive | `#EF4444` (`--destructive` / `--semantic-error`) | Validation-fail states only |

**Accent (`#35BFAD`) reserved for — explicit list:**
- The primary **"Publicar vaga"** CTA (filled accent button).
- The selected/active state of the chosen template card in TemplateVagaSelector.
- The slider filled-track + thumb when the live sum **equals 100%** (valid state).
- The `fortemente_pontua` tag badge (strongest positive scoring tag).

Accent is NOT used for: secondary buttons, all interactive hovers, links, or generic borders.

**Tag taxonomy color mapping (CONTEXT D-11 — 5 tags of `enum_tag_opcao`).** These are
**semantic status colors**, intentionally outside the 60/30/10 accent budget (they encode
data meaning, like success/error, not visual emphasis):

| Tag | Badge color | Token |
|-----|-------------|-------|
| `knockout` | `#EF4444` (error red) | `--semantic-error` |
| `atencao` | `#F59E0B` (warning amber) | `--semantic-warning` |
| `neutro` (default / "informativa") | `#86898C` (neutral-600, muted) | `--neutral-600` |
| `pontua` | `#10B981` (success green) | `--semantic-success` |
| `fortemente_pontua` | `#35BFAD` (brand-accent) | `--brand-accent` |

**Live-sum validation feedback:**
- Sum **= 100%** → accent `#35BFAD` text + valid slider tracks.
- Sum **≠ 100%** → `#EF4444` inline error text "Soma: X% (faltam Y%)" (CONTEXT D-08). Never
  silent-rebalance; sliders stay where the user left them.

## Copywriting Contract

All copy is **pt-BR** (project domain language convention, CLAUDE.md).

| Element | Copy |
|---------|------|
| Primary CTA | **"Publicar vaga"** (reuses rascunho→ativa transition, CONTEXT D-03; gated by D-12 validation) |
| Secondary CTA | **"Salvar rascunho"** (no validation fires — CONTEXT D-12: rascunho não valida nada) |
| Optional helper button | **"Normalizar para 100%"** (CONTEXT D-08 — explicit user action, never automatic) |
| Bulk-mark action | **"Marcar tudo como informativa"** (BulkMarkDialog trigger; sets every option to neutro + peso 0 + nota_ia null) |
| Empty state heading | **"Nenhuma pergunta de escolha nesta vaga"** |
| Empty state body | **"O assistente de tags aparece só para perguntas de escolha única ou múltipla. Adicione perguntas na aba Perguntas para marcá-las aqui."** (CONTEXT D-11 — wizard só renderiza para `single_choice`/`multiple_choice`) |
| Live-sum indicator (valid) | **"Soma: 100% — pesos prontos para publicar"** |
| Live-sum indicator (invalid) | **"Soma: {X}% (faltam {Y}%)"** with `#EF4444` (CONTEXT D-08 / RF-34) |
| Error — pesos ≠ 100% (on Publicar) | **"Os pesos precisam somar 100% antes de publicar. Ajuste os sliders (faltam {Y}%)."** |
| Error — no obligatory test (on Publicar) | **"Selecione ao menos um teste obrigatório antes de publicar a vaga."** (CONTEXT D-12 / RF-11) |
| Error — knockout sem pergunta obrigatória (on Publicar) | **"A pergunta \"{texto}\" tem uma opção eliminatória (knockout) mas não está marcada como obrigatória. Marque-a como obrigatória para publicar."** (CONTEXT D-12 / RF-02) |
| Template selected confirmation | **"Template {cargo} aplicado. Você pode ajustar pesos e testes nesta vaga."** (CONTEXT D-04 — copies defaults, override allowed) |
| Destructive confirmation | **Trocar template:** "Trocar o template vai sobrescrever os pesos e testes atuais desta vaga pelos padrões do novo template. As tags marcadas nas perguntas são mantidas. Trocar template?" |

**Validation timing (CONTEXT D-12 / RF-36):** all three publish-gate errors fire **only on the
"Publicar vaga" click** — progressive validation. The live "Soma" indicator updates continuously
as a non-blocking hint, but it does not block or toast until Publicar.

**Destructive actions in this phase:**
- **Trocar template** (overwrites pesos + testes_aplicaveis of the current vaga) → confirm via
  `AlertDialog` (already vendored as `alert-dialog.tsx`). This is the only destructive action;
  it is data-overwrite, not deletion. Marking tags is non-destructive (re-markable). "Marcar tudo
  como informativa" is a bulk **reset to default** — reversible, so a lightweight `Dialog`
  confirm ("Isto vai marcar todas as opções desta pergunta como informativa. Continuar?") suffices,
  not an AlertDialog.

## Interaction Notes (for planner + executor)

Block-level interaction contract derived from CONTEXT decisions. Not a layout spec — these are
the load-bearing behaviors the executor must honor.

**Focal point / visual hierarchy:** The primary visual anchor is the accent-filled "Publicar vaga"
CTA (the gated terminal action of the screen). The secondary anchor is the live "Soma: X%"
indicator in the PesosSliders block — it carries the most critical real-time state (valid green at
100%, red otherwise) and is what the RH user watches while configuring. Block reading order is
TemplateVagaSelector → PesosSliders → Tag Wizard, separated by the `2xl` (48px) token; the legacy
tabs shell frames all three without competing for emphasis.

**TemplateVagaSelector (CONTEXT D-04):**
- Renders the 8 cargo templates from a TS config module (`dentista`, `recepcionista`,
  `consultor_vendas_premium`, `sdr_social_seller`, `assistente_financeiro`, `asb`, `tsb`,
  `vaga_generica`). RH selects one; UI **copies** defaults into `vaga.testes_aplicaveis` +
  `vaga.pesos_avaliacao`. Override happens on the vaga, never on the template.
- Selected template card: accent `#35BFAD` active state. Re-selecting a different template →
  "Trocar template" AlertDialog (overwrite warning above).

**PesosSliders (CONTEXT D-07, D-08):**
- Exactly **4 sliders** that sum to 100%: `triagem`, `work_sample_sjt`, `redacao_cultural`,
  `entrevista`. `big_five` and `cognitivo` render as **read-only context chips** (no peso, not in
  the sum) — visually de-emphasized (neutral, muted), clearly labelled "contexto — não pontua".
- **Free sliders + inline error. No silent rebalance.** Live "Soma: X%" indicator updates on every
  drag. Sum ≠ 100% → red inline text; "Publicar vaga" blocked. Optional "Normalizar para 100%"
  button is the only way the system touches the values, and only on explicit click.

**Tag Wizard — PerguntaWithTagsForm + BulkMarkDialog (CONTEXT D-10, D-11):**
- Only renders for `single_choice` / `multiple_choice` questions. Text/numeric questions show the
  empty-state copy above (or are simply skipped from the wizard list).
- Each option row: tag `Select` (5 tags) + `peso` numeric input (range −999..100, default 0) +
  `nota_ia` text (nullable). Unmarked option = `neutro` + peso 0 + nota_ia null ("informativa").
- Tag badges colored per the taxonomy table above.
- "Marcar tudo como informativa" (BulkMarkDialog) applies neutro/0/null to all options of the
  question in one click, with the lightweight confirm dialog.

**Persona / responsiveness:** desktop-first internal tool. No mobile breakpoint contract required;
inherits the legacy desktop Tabs shell. Min hit target 44px on the interactive controls listed in
Spacing exceptions.
