# Phase 13 — UI Design Contract

> Visual and interaction contract for **Redação Cultural + Revisão Humana** (Etapa 3, camada redação). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Two surfaces, two personas:**
> 1. **CANDIDATE essay screen** (mobile-first, public glass-over-gradient persona): a single open essay of **200-500 words** with a live word counter, hard min/max submit gating, the established `useAutosaveAvaliacao` "salvo automaticamente" affordance, and an informative (non-countdown) cronômetro. The candidate **never** sees a score, a color, a threshold, or any pass/fail framing while writing (RNF-07a). The 3-color system is **RH-facing triage only** and is NOT shown to the candidate as a verdict.
> 2. **RH human-review queue** (desktop-first, internal admin persona, role-gated): **1-redação-por-vez**, a color-coded sidebar of pending essays ordered by severity (vermelho → amarelo → verde), per-dimension **BARS slider** override, mandatory `notas_revisor` (≥50 chars on every decision), and a `decisao_revisor` radio (aprovado / reprovado / duvida) where **duvida escalates to the gestor**.
>
> **Binding spec:** `docs/prds/m2-funil-rh/PRD-redacao-fit-cultural.md` v1.1 (§6.1 editor, §6.3 RH review, §7 RNF, §8 schema/RLS). `docs/prds/fit-cultural-prd.md` is DEPRECATED — do not use. Covers AVAL-05, AVAL-06, AVAL-07.

## Spacing Scale

Declared values (multiples of 4; matches the existing glass shell which scored 4/4 on spacing in Phase 11/12 — `space-y-4/5/6/8`, `gap-2/3/4`, `p-6`, `py-20`):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps inside badges/status pills/color chips (`gap-1`) |
| sm | 8px | Compact element spacing, slider-to-value gaps, radio inner padding (`gap-2`) |
| md | 16px | Default gap between form blocks, sidebar list items, dimension rows (`space-y-4`, `gap-4`) |
| lg | 24px | Card/panel inner padding (`p-6`), gap between major sections (`space-y-6`) |
| xl | 32px | Container vertical rhythm between panels (`space-y-8`) |
| 2xl | 48px | Header-to-content break, empty/all-done/locked state vertical padding (`p-12`) |
| 3xl | 64px | Page top/bottom breathing room (`py-20` from candidate shell) |

**Exceptions:** Touch targets on the **candidate** side (primary CTA, navigation buttons, next-question buttons) carry the established `min-h-[44px]` mobile a11y floor (44 = 4×11, on-scale but outside the named set — inherited from Phase 11/12). On the **RH desktop** side, slider thumbs (`size-4` = 16px, on-scale) are mouse targets and do not require the 44px floor, but RH action buttons (`A`/`R`/`D`, J/K nav, Salvar revisão) carry `min-h-[44px]` for consistency.

## Typography

Family: Helvetica Neue (`--font-family`). Exactly 4 sizes, 2 weights. Body line-height 1.5, heading line-height 1.2. Candidate surface text is white with `drop-shadow-md` over the gradient (shell convention).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / essay textarea / reasoning / notes | 16px (`text-base`) | regular (400) | 1.5 |
| Label / counter / status pill / autosave note / slider value | 14px (`text-sm`) | semibold (600) | 1.4 |
| Card title / question prompt heading / dimension name | 20px (`text-xl`) | semibold (600) | 1.2 |
| Page heading (candidate H1 / RH panel H1) | 28px (`text-3xl`, responsive `md:text-4xl` cap) | semibold (600) | 1.2 |

**Notes:**
- The 14px/16px proximity is intentional and perceptually separated by **weight** (14 = semibold label, 16 = regular body), matching the approved Phase 11/12 contract — not a 14/15/16 micro-band.
- **Essay reading on the RH side is load-bearing** (PRD RF-R-22): the right panel renders the full essay text at **16-18px / line-height 1.6** for careful reading — use `text-base leading-relaxed` (≈16px/1.625) minimum; never compress essay text below 16px even when long. This is the one place line-height goes to 1.6+ instead of 1.5.
- The candidate essay textarea body is 16px at 1.5 — comfortable typing on mobile, never smaller.
- Only two weights: 400 (essay body, reasoning, notes, prompt body) and 600 (titles, labels, counters, CTAs, decisão labels). No 500/700/800 despite availability. The `md:text-4xl` heading cap is a responsive variant on the top scale role (Phase 11/12 precedent), not a 5th semantic size.

## Color

The candidate side is the **glass-over-gradient** persona surface (translucent white over the brand gradient). The RH side is the **desktop brand panel** surface. The 3-color triage system lives **only** on the RH side.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#00109E` brand-primary (gradient on candidate via `BackgroundImage`; solid brand panel on RH) | Full-page background behind all glass/panels |
| Secondary (30%) | `bg-white/5`–`bg-white/20` translucent white (GlassCard/GlassPanel/Glass) | Essay panel, form panels, navbar, sidebar, status pills |
| Accent (10%) | `#35BFAD` brand-accent | See reserved list below |
| Destructive | `#EF4444` (`--destructive`) | "Reprovar" confirm affordance + error/load-failed iconography ONLY |

**Accent (`#35BFAD`) reserved for — explicit list:**
1. The candidate **"Salvo automaticamente"** autosave affordance (check icon + text tint) — the single accent touchpoint while writing.
2. The candidate **in-range word counter** state (200-500 words = `#35BFAD`) — "you're in the valid band". (Below-min and above-max are neutral/amber, NOT red — see triage rule below.)
3. The RH **`SugestaoIABadge`** accent tint (`border-[#35BFAD]/40 bg-[#35BFAD]/10`, Sparkles) on every AI-derived block — RH panel only, never candidate-facing.

Accent is NOT used for: the candidate primary CTA, the RH decisão buttons, slider fills, links, or generic hover. The candidate CTA and RH buttons use glass-white (`bg-white/20` → `bg-white/30`). This keeps accent rare.

### Candidate word counter — code-of-colors (PRD RF-R-02), NOT a verdict

The counter colors communicate the **length band**, not quality — they are mechanical writing guidance, never a score/pass-fail signal (RNF-07a holds: a short counter means "too short", not "you failed"):

- **< 200 words** → muted neutral `text-white/60` + helper "**{N} palavras — mínimo 200**". (Use neutral muted, NOT alarm-red, to avoid pass/fail framing.)
- **200-500 words** → `#35BFAD` accent + helper "**{N} palavras**" — in the valid band, submit enabled.
- **> 500 words** → `text-amber-300/80` warning tint + helper "**{N} palavras — máximo 500**". (Warm warning, not destructive-red.)

### RH 3-color triage system (RH-facing only — PRD RF-R-17/23/26)

The 3 colors are the RH review-priority signal. They appear on the sidebar chips, the per-essay `RedacaoCorBadge`, and the sort order — never on a candidate surface:

- 🟢 **verde** (`score ≥ amarelo_max+1`, default ≥65) → `bg-emerald-500/15 text-emerald-300 border-emerald-400/30` (a triage color, distinct from the `#35BFAD` accent role).
- 🟡 **amarelo** (`41-64`) → `bg-amber-500/15 text-amber-300 border-amber-400/30`.
- 🔴 **vermelho** (`≤40 OR red_flag_etico OR D1≤2`) → `bg-red-500/15 text-red-300 border-red-400/30` + a top-of-essay badge whose tooltip names the firing rule ("score ≤40" / "red flag ético" / "D1≤2").

Sidebar default filter = **vermelho + amarelo** (verde shown on demand). Sort = severidade DESC (vermelho first).

## Copywriting Contract

All copy pt-BR. Product-language rule (RNF-R-11 / LGPD-04): use **"redação cultural" / "avaliação comportamental"**, NEVER "teste psicológico". Candidate copy is neutral and reassuring — no scores, no colors, no "aprovado/reprovado", no feedback on quality (PRD RF-R-06: "Resposta registrada" only).

| Element | Copy |
|---------|------|
| Primary CTA (candidate, per-question submit) | **Enviar redação** |
| Empty state heading (candidate — no essay configured) | **Nenhuma redação pendente** |
| Empty state body (candidate) | Você não tem redação para concluir nesta etapa no momento. |
| Error state (candidate load failed) | **Não foi possível carregar a redação.** Verifique sua conexão e tente novamente. *(+ Tentar novamente)* |
| Destructive confirmation (RH reprovar) | **Reprovar redação?** — Esta decisão segue para o gestor da vaga apenas em caso de dúvida. Justifique abaixo (mínimo 50 caracteres). — Confirm: **Reprovar** / Cancel: **Voltar** |

### Candidate submit confirmation (irreversible, not destructive)

There are **no delete actions** on the candidate side. Submitting an essay is irreversible after "Concluir Etapa 3" (edit locked, PRD RF-R-07). Gate with `alert-dialog`:

| Action | Confirmation |
|--------|--------------|
| Enviar redação | Title: **Enviar redação?** — Body: **Você ainda pode revisá-la até concluir esta etapa.** — Confirm: **Enviar** / Cancel: **Continuar escrevendo** |
