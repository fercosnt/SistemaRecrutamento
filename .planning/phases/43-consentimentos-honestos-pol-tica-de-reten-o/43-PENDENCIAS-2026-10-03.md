## SQL proposto para a captura do drift (W-9 + D-4). NÃO aplicado

Definições lidas de `pg_policies` e `pg_trigger` em PROD em 2026-10-03. Usa `IF NOT EXISTS`, então em PROD não muda nada.

```sql
DO $$
BEGIN
  IF NOT EXISTS (SELECT 1 FROM pg_policies WHERE schemaname='public' AND tablename='autorizacoes' AND policyname='Candidatos podem ler suas autorizacoes') THEN
    CREATE POLICY "Candidatos podem ler suas autorizacoes" ON public.autorizacoes FOR SELECT TO authenticated
      USING (EXISTS (SELECT 1 FROM public.candidatos c WHERE c.id = autorizacoes.candidato_id AND c.user_id = auth.uid() AND c.deleted_at IS NULL));
  END IF;
  IF NOT EXISTS (SELECT 1 FROM pg_policies WHERE schemaname='public' AND tablename='autorizacoes' AND policyname='Candidatos podem atualizar suas autorizacoes') THEN
    CREATE POLICY "Candidatos podem atualizar suas autorizacoes" ON public.autorizacoes FOR UPDATE TO authenticated
      USING      (EXISTS (SELECT 1 FROM public.candidatos c WHERE c.id = autorizacoes.candidato_id AND c.user_id = auth.uid() AND c.deleted_at IS NULL))
      WITH CHECK (EXISTS (SELECT 1 FROM public.candidatos c WHERE c.id = autorizacoes.candidato_id AND c.user_id = auth.uid() AND c.deleted_at IS NULL));
  END IF;
  IF NOT EXISTS (SELECT 1 FROM pg_policies WHERE schemaname='public' AND tablename='autorizacoes' AND policyname='RH pode ler todas as autorizacoes') THEN
    CREATE POLICY "RH pode ler todas as autorizacoes" ON public.autorizacoes FOR SELECT TO authenticated
      USING (EXISTS (SELECT 1 FROM public.usuarios_rh u WHERE u.user_id = auth.uid() AND u.ativo = true AND u.deleted_at IS NULL));
  END IF;
  IF NOT EXISTS (SELECT 1 FROM pg_trigger WHERE tgrelid='public.autorizacoes'::regclass AND tgname='update_autorizacoes_updated_at') THEN
    CREATE TRIGGER update_autorizacoes_updated_at BEFORE UPDATE ON public.autorizacoes
      FOR EACH ROW EXECUTE FUNCTION public.update_updated_at_column();
  END IF;
END $$;
```

⚠ **A função `update_updated_at_column()` também é drift.** Medido: zero ocorrências de `FUNCTION … update_updated_at_column` em `supabase/migrations/`. A captura tem de incluí-la antes do trigger (`CREATE OR REPLACE FUNCTION public.update_updated_at_column() RETURNS trigger LANGUAGE plpgsql SET search_path TO 'public' AS $f$ BEGIN NEW.updated_at = NOW(); RETURN NEW; END; $f$;`, que é a definição lida de PROD). Num banco recriado, o `CREATE TRIGGER` falharia sem ela.
