| RPC error → UI copy | error must surface as static PT-BR copy keyed by code, never the raw RPC/PII string |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-20-16 | Info disclosure (raw error/PII echoed in UI) | save-error region | mitigate | AsyncState contract: static PT-BR copy keyed by errorCode (FORBIDDEN/insufficient_privilege → permission copy); never echo the raw RPC error (T-18-04-ID) |
| T-20-17 | Tampering (client posts a score/band) | edit state → onSaveEdits payload | mitigate | the UI only edits pergunta/dimensão/origem/order; no score field is editable; the RPC stores opaque jsonb; guide never feeds candidaturas (RNF-07a) |
