RPC `public.funil_kpis(p_vaga_id uuid DEFAULT NULL)` returns a single jsonb with 7 keys (34-01 extended):
  median_time_per_stage: { [etapa]: seconds }        — bigint seconds per stage
  conversion_stage_to_stage: [{ de, para, n }]        — raw stage→stage counts
  volume_by_stage: { [etapa]: n }                     — current volume by etapa_atual
  time_to_hire: bigint seconds | null                 — median inscrição→aprovado (client → days)
  knockout_rate: { knockouts, total, taxa|null }
  drop_per_stage: { [etapa]: { dropped, saidas, taxa|null } }
  no_show_rate: { no_shows, total, taxa|null }
Vaga-scoped + PII-free by construction (SEG-02); an all-empty/{}/null result = no data (render the empty state, never a
  fabricated 0). time_to_hire display: seconds → days = round(secs/86400, 1); a null taxa/time renders "—".

Chart wrapper (clone AiCostsPage.tsx:14-51): import chart PRIMITIVES (BarChart, Bar, XAxis, CartesianGrid) from
  `recharts`, and ChartContainer/ChartTooltip/ChartTooltipContent/ChartConfig from `@/components/ui/chart`. Each
  ChartContainer uses a ChartConfig with `--chart-1..5` tokens + `className="h-56 w-full"` + `accessibilityLayer` on the
  chart + `<ChartTooltip content={<ChartTooltipContent />} />`. NEVER import ResponsiveContainer/Tooltip directly (Pitfall 6).

RelatoriosRHPage (`src/components/pages/RelatoriosRHPage.tsx`, ~1229 lines, exported `RelatoriosRHPage` at :712) is

  name + the RHLayout host so the route is unchanged. The dead M1 hooks (useRelatoriosStats/useDistribuicaoDISC/etc.,
