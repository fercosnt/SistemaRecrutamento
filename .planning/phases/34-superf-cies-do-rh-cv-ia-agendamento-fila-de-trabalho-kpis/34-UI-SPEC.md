# Phase 34 — UI Design Contract

> Visual and interaction contract for the four RH-facing surfaces of Phase 34:
> (1) CV/IA/Histórico blocks in `HubCandidatoRH`, (2) the interview-scheduling form,
> (3) the cross-vaga work-queue "Fila" tab, (4) the KPI dashboard that replaces
> `RelatoriosRHPage`. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Guiding rule (from CONTEXT §Boundary):** MATCH the existing Beauty Smile glass RH
> surfaces — do NOT invent new visual language. Every new block is a sibling of an
> existing `<HubSection>`/`<Glass>`/`GlassCard`. Zero new npm; zero new UI primitive
> (all shadcn primitives already vendored under `src/components/ui/`).

## Color

60/30/10 split for the RH dark-glass surfaces (matches every shipped RH surface — `HubCandidatoRH`, `TriagemTable`, `AiCostsPage`, `CandidatosRHPage`):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | dark glass `bg-black/30` (`<Glass variant="dark" blur="lg">`) over the RH branded gradient; text `text-white` / `text-white/80` / `text-white/70` | All content panels — hub sections, agendamento block, fila table shell, dashboard cards |
| Secondary (30%) | white glass `bg-white/10`–`bg-white/15` (`<Glass variant="white">`) | Tab bar, table header rows, inline neutral chips, secondary cards |
| Accent (10%) | turquoise `#35BFAD` = `hsl(var(--accent))` = `bg-accent`/`text-accent` (also `--chart-2`) | See reserved list below |
| Destructive | red `#EF4444` = `hsl(var(--destructive))` = `bg-destructive` (`red-500/*` in glass form) | Reject action, Cancelar entrevista, SLA breach badge, no-show indicator |

**Accent (turquoise) reserved for — explicit list, never "all interactive elements":**
1. The single dominant CTA per surface (e.g. `Agendar entrevista`, `Abrir workspace de …`) — solid `bg-accent`.
2. The current-etapa chip and the "Próximo passo" eyebrow label.
3. The AI signal (`Sparkles` icon + "Análise da IA" accents) — subordinate, `opacity-70`.
4. Active tab emphasis + the primary chart series (`--chart-2`) / focus states.

**Token discipline (CLAUDE.md + memory `bg_primary_token_fixed`):**
- Deep blue is `bg-primary` = `hsl(var(--primary))` (`#00109E`, also `--chart-1`, `--ring`). **Never** hardcode the hex `#00109E`; use `bg-primary` / `text-primary` / the `--primary` token.
- Prefer semantic tokens `bg-accent`/`text-accent` for turquoise in NEW code. The arbitrary hex `[#35BFAD]` is the value already used across RH surfaces; matching it stays visually identical, but `bg-accent` (same computed value) is the preferred form.

**Semantic / status palette (data-encoding — NOT part of the 10% accent budget):**

| Meaning | Class | Where |
|---------|-------|-------|
| Score band ≥70 (good) | `bg-green-500/20 text-green-300 border-green-500/30` | IA `score_match` chip (reuse `scoreBandClass`) |
| Score band 40–69 (mid) | `bg-yellow-500/20 text-yellow-200 border-yellow-500/30` | IA `score_match` chip |
| Score band <40 (low) | `bg-red-500/20 text-red-300 border-red-500/30` | IA `score_match` chip |
| Score band null (—) | `bg-white/10 text-white/50 border-white/20` | IA no-analysis |
| SLA aging (warning) | `bg-yellow-500/20 text-yellow-200 border-yellow-500/30` (`--semantic-warning` #F59E0B) | Fila badge — time-in-stage ≥ threshold |
| SLA breach | `bg-red-500/20 text-red-300 border-red-500/30` | Fila badge — time-in-stage > breach threshold |
| Agendamento status | `agendada`/`reagendada` = accent glass · `concluida` = green · `cancelada`/`nao_compareceu` = red · `pendente compareceu` = neutral white glass | Agendamento summary chip |

Contrast: all body text is white/near-white on `bg-black/30` glass → passes WCAG AA (established in prior UI-SPECs). Every band/badge carries a **text label or number in the same element as the color** — never color-only (colorblind-safe; the `ScoreCell` invariant).

## Accessibility (WCAG 2.1 AA — axe-core Tier-A precedent)

- **Color never sole channel:** score bands, SLA badges, and agendamento status chips each carry a **text label / number** in the same element as the color (colorblind-safe — the `ScoreCell` invariant).
- **Contrast:** white / `text-white/80` body on `bg-black/30` glass passes AA; the accent turquoise is used for large/bold text or non-text UI, not small low-contrast body.
- **aria-live:** async result regions and mutation feedback announce politely (`aria-live="polite"` / `aria-busy` on the CV button and agendamento save) — P21 autosave precedent.
- **Keyboard:** `Calendar`, `Popover`, `Select`, `AlertDialog`, `Tabs`, `ToggleGroup` are Radix — full keyboard nav + focus trap + `Esc` for free. New "Fila" tab is reachable via the roving tabindex of the existing `TabsList`.
- **Focus visible:** the global `outline-ring/50` (`--ring` = `#00109E`) ring is preserved; do not remove focus outlines on the new controls.
- **Touch targets:** every interactive control ≥ 44px (`min-h-[44px]`).
- **Icon-only buttons:** always an `aria-label`; decorative leading icons `aria-hidden="true"`.
- **Charts:** each `ChartContainer` gets an accessible title (the card `<h2>`); recharts' `accessibilityLayer` enabled where available so series are keyboard-inspectable; a data caption/summary accompanies each chart for screen readers.
- **Destructive confirm:** Cancelar entrevista uses `AlertDialog` (role=alertdialog) with a clear, non-color-only warning.

## Responsive (desktop-first, internal RH)

- **Hub:** single-column `space-y-6` stack; blocks are full-width and reflow naturally. Action rows use `flex flex-wrap gap-2`.
