## Agendamento Card — Layout & Interaction Contract

**Mount point:** replaces the existing "Próximo passo" footer block (`DashboardCandidatoPage.tsx` ~L379-398) **only** when `candidatura.etapa_atual` is `entrevista_online` or `entrevista_presencial`. All other etapas are **unchanged** — the existing neutral/turquoise CTA footer stays exactly as-is.

Rationale: today `funilNavMap` returns `rotaCandidato: () => null` for both entrevista etapas, so the existing footer button is a dead no-op for these two stages. This card replaces that dead affordance with real information.

**Structure (mobile-first, single column; fields stack top-to-bottom, full width):**

```
┌─────────────────────────────────────────────┐
│ SUA ENTREVISTA                               │  ← eyebrow, replaces "Próximo passo"
│                                               │
│ [●Agendada]  [Online]                        │  ← status chip + tipo chip, flex-wrap gap-2
│                                               │
│ 20/07/2026 às 14:30 (horário de Brasília)    │  ← data/hora, body text
│                                               │
│ [ Entrar na videochamada ]                   │  ← turquoise pill/link, min-h 44px (online)
│   — or —                                     │
│ Local: Av. Paulista, 1000 — sala 4           │  ← plain text (presencial)
│                                               │
│ [amber] Sua entrevista é em menos de 24h     │  ← only if upcoming + non-cancelled + <24h
│                                               │
│ [ ⬇ Adicionar à agenda (.ics) ]              │  ← turquoise button, min-h 44px, only if
│                                               │     upcoming + non-cancelled
└─────────────────────────────────────────────┘
```

- Status chip + tipo chip sit on the same row on `sm+`, wrap on narrow (`flex flex-wrap gap-2`).
- Tipo chip is a **neutral** pill (`bg-white/10 border border-white/20 text-white/80 rounded-lg px-3 py-1.5 text-sm`), icon `Video` (online) / `MapPin` (presencial) — never colored, it's not a status signal.
- The `.ics` button, when present, is the **last** element in the block (bottom, most-recent action).
- Container: `mt-4 border-t border-white/10 pt-4 flex flex-col gap-3` — reuses the existing footer's top border/padding verbatim.

**Field source (allowlist — never more than these 7 columns from `get_meu_agendamento`):** `id, candidatura_id, tipo, data_hora, local_ou_link, status, compareceu`. `compareceu` is not rendered in this card (no requirement calls for it candidate-side); `observacoes_rh`/`entrevistador`/`agendado_por`/`vaga_id`/`updated_by` are physically absent from the RPC result — never attempt to read them.

**Link vs. plain text (CONTEXT, LOCKED):**
- `tipo='online'` → `local_ou_link` rendered as a clickable pill/link: `<a href={local_ou_link} target="_blank" rel="noopener noreferrer">`.
- `tipo='presencial'` → `local_ou_link` rendered as plain text, prefixed `Local:`, never a link even if it happens to look like a URL.

## States Contract

| State | Trigger | Rendering |
|-------|---------|-----------|
| **loading** | `get_meu_agendamento` query in flight (etapa is entrevista_*, first load) | Compact 2-line skeleton pulse inside the footer area (`h-4 bg-white/10 rounded animate-pulse`, `h-3 w-2/3 bg-white/10 rounded animate-pulse`) — same pulse idiom as the page's existing candidatura-list skeleton, scaled down to footer size |
| **no-agendamento** | Query resolved, 0 rows (RH hasn't scheduled yet) | Compact neutral note: eyebrow `Sua entrevista` + icon `CalendarClock` + `Aguardando agendamento` / `O RH ainda não agendou sua entrevista. Assim que a data for definida, ela aparecerá aqui.` — no chip, no button |
| **has-agendamento (non-cancelled)** | Query resolved, 1 row, `status ≠ 'cancelada'` | Full card per Layout Contract: status + tipo chips, data/hora, link/local, conditional 24h badge, conditional `.ics` button |
| **cancelada-visible** | Query resolved, most-recent row `status = 'cancelada'` | Full card renders (status/tipo/data/local shown), but data/hora + local/link rows are **dimmed** (`opacity-70`) and the status chip is the red `Cancelada` chip (prominent, undimmed). Inline note below: `Esta entrevista foi cancelada. Você será avisado aqui se uma nova data for marcada.` **No** 24h badge, **no** `.ics` button — ever, regardless of date. |
| **error** | RPC/query threw (network, RLS, etc.) | Compact inline error, does NOT block the rest of the candidatura card: `Não foi possível carregar os detalhes da sua entrevista.` + `Tentar novamente` button (`min-h-[44px]`, re-triggers `refetch()`) |

`reagendada` and `em_andamento`/`concluida`/`nao_compareceu` all fall under **has-agendamento** — same layout, only the status chip color/label + inline note (reagendada only: `O horário da sua entrevista foi atualizado.`) change. The card **always renders** once a row exists — no status is ever hidden (CONTEXT: "Card sempre renderiza").

## `.ics` Download & ≤24h Reminder Badge Contract

Both are gated by the **same rule** (CONTEXT, LOCKED): visible **only when** `data_hora` is in the future **AND** `status ≠ 'cancelada'`.

- **≤24h reminder badge:** additionally requires `0 < (data_hora − now) ≤ 24h`. Amber chip (semantic warning token, reused verbatim from `EntrevistaDashboard.tsx`'s FX-07-fixed pair): `bg-amber-500/25 text-amber-100 border-amber-300/40`, icon `CalendarClock` (`aria-hidden`), label `Sua entrevista é em menos de 24h`. Computed client-side, pure function of `data_hora` and `now` — no new column, no server round-trip.
- **`.ics` download button:** `Adicionar à agenda (.ics)` (icon `Download`), solid turquoise (`bg-[#35BFAD] hover:bg-[#35BFAD]/90`), `min-h-[44px]`. On click: generates a hand-rolled `VCALENDAR` string client-side (mirrors `biasAuditService.ts:147-148`'s `Blob`+`URL.createObjectURL`+temporary `<a download>` idiom) — `SUMMARY: Entrevista Beauty Smile` (generic; `vaga_id` is outside the allowlist so no vaga name), `DTSTART` = `data_hora` in UTC (`Z` suffix — the column is `timestamptz`), `DTEND` = `DTSTART` + 1h, `LOCATION` = `local_ou_link`. No RH-internal PII in the file. No loading state (synchronous).

## Accessibility (WCAG 2.1 AA — axe-core Tier-A precedent)

- **Color never sole channel:** status chip, tipo chip, and the 24h badge each carry a **text label in the same element** as the color (colorblind-safe — see semantic palette table).
- **Contrast:** reuses only AA-proven token pairs already shipped in this codebase — the file's own `getStatusInfo` chip classes (status) and the FX-07-fixed amber pair (24h badge). Do not invent new low-contrast combinations.
- **Touch targets ≥44px:** the `.ics` button and the "Entrar na videochamada" link/pill both use `min-h-[44px]` (Phase 34 UI-review finding, honored here). The video link is styled as a **bordered pill with padding**, not a bare underlined inline text link — this both meets the touch-target minimum and visually signals "tappable," consistent with the rest of the page.
- **Accessible names:**
  - `.ics` button: visible label `Adicionar à agenda (.ics)` is the accessible name; optionally reinforce with `aria-label="Adicionar entrevista à agenda, baixar arquivo .ics"`.
  - Video link: `aria-label="Entrar na videochamada da entrevista (abre em nova aba)"` (external link + new-tab must be announced — the visible label alone doesn't convey "opens in a new tab").
  - Retry button (error state): visible label `Tentar novamente` is sufficient (no separate aria-label needed).
- **Date/time is real text, screen-reader readable by construction** (`formatDataHoraSP` returns a plain pt-BR string, not an image/icon-only glyph). Recommended reinforcement: wrap the data/hora line in a container with `aria-label` using the natural long form (e.g. `Intl.DateTimeFormat('pt-BR', { dateStyle: 'long', timeStyle: 'short', timeZone: 'America/Sao_Paulo' })` → "20 de julho de 2026 às 14:30") so screen readers announce a fluent sentence instead of the abbreviated `dd/mm/aaaa às hh:mm` — visible text stays the short form.
- **Icons:** every icon in this card (`CalendarCheck`, `Video`, `MapPin`, `RefreshCw`, `AlertCircle`, `CheckCircle2`, `Clock`, `CalendarClock`, `Download`) is `aria-hidden="true"` — the adjacent text label carries the meaning.
- **Focus visible:** the global focus ring is preserved on the `.ics` button and the video link/pill — no `outline-none` without a replacement.

## Responsive (mobile-first, public candidate theme)

- Card is embedded inside the existing per-candidatura `GlassCard`, which is already full-width and responsive — no new breakpoint container needed.
- All rows stack vertically (`flex flex-col gap-3`) on mobile; status + tipo chips sit side-by-side on `sm+` via `flex flex-wrap gap-2` (wrap gracefully on narrow viewports, never truncate/clip text).
- `.ics` button: `w-full sm:w-auto` (full-width tap target on mobile, natural width on larger screens).
- Long `local_ou_link` values (long meeting URLs or addresses) wrap (`break-words`), never overflow the card horizontally.
- No horizontal scroll, no fixed pixel widths — everything fluid within the parent `GlassCard`'s padding.
