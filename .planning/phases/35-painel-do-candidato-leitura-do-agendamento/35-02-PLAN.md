| RH-authored `local_ou_link` → candidate DOM (`<a href>`) | A stored field is rendered as a link for online interviews — output-encoding boundary. |
| RH-authored `local_ou_link` → `.ics` TEXT fields | Stored text is embedded into a downloadable calendar file — injection boundary. |
| candidate browser → Supabase RPC | Same as 35-01: only `candidatura_id` crosses; ownership + allowlist are server-enforced. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-35-03 | Tampering / XSS-ish | `local_ou_link` rendered as `<a href>` | mitigate | Link rendered ONLY when `tipo='online'`, with `rel="noopener noreferrer" target="_blank"`; `tipo='presencial'` is always plain text (never a link). React text nodes are auto-escaped. Grep-gated in Task 2. |
| T-35-04 | Tampering | `.ics` injection via unescaped CRLF/`;`/`,` in `local_ou_link` | mitigate | `escapeIcsText` escapes `\ , ; \n` in SUMMARY/LOCATION; the builder controls the `\r\n` line joins, not the field content (Task 1, Pitfall 3). |
| T-35-01 | Information Disclosure | card renders no RH-internal field | mitigate | The card consumes only `MeuAgendamentoRow` (7 allowlist cols from the 35-01 RPC). `observacoes_rh`/`entrevistador`/`vaga_id` are physically absent from the row; the `.ics` SUMMARY is the generic constant (no vaga name). No `select('*')`, no base-table read introduced. |
| T-35-02 | Information Disclosure / Elevation | cross-candidate read | accept (server-enforced) | Ownership enforced inside `get_meu_agendamento` (Phase 33, 9/9 smokes). The card passes only `candidatura.id` (the candidate's own listed candidatura); no client control added. |
| T-35-SC | Tampering (supply chain) | npm/pip/cargo installs | N/A | Zero new packages this phase (LOCKED). `.ics` is deliberately hand-rolled to avoid an `ics`/`ical-generator` dependency. No install task; no legitimacy gate needed. |
