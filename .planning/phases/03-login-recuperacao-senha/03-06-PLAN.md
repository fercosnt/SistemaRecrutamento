<threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Form input → requestPasswordReset | Untrusted email crosses to SDK; response must NEVER distinguish exist/not-found (D-09) |
| Email deeplink → /auth/redefinir-senha | Hash fragment carries recovery JWT; browser URL bar may display; validated via useRecoverySession |
| updateUser success → auto-login fallback | tryAutoLogin fires only on session_expired; accepts email from recovery session (not user input) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02 | Info Disclosure | EsqueciSenha post-submit UI leaks whether email is registered | mitigate | Post-submit card renders IDENTICALLY for success + not-found; passwordService swallows non-rate-limit errors. UI never displays `{emailValue}` (UI-SPEC L491 kills the scaffold echo) |
| T-03-05 | Spoofing | User clicks expired or already-consumed recovery link | mitigate | useRecoverySession maps invalid/expired/missing session → `status: 'invalid'`; RedefinirSenhaPage renders InvalidLinkState with "Solicitar novo link" CTA that navigates to /auth/esqueci-senha |
| T-03-08 | Tampering | Client bypasses Zod silent validation | accept | Server-side Supabase `updateUser` rejects weak passwords (error.code='weak_password'); mapSupabaseError surfaces as SERVER_ERROR toast. Zod is UX-only per D-11. |
| T-03-03 | Info Disclosure | nova_senha logged in onSubmit catch via `console.error(err)` | mitigate | Page never logs form data; authService/passwordService already redact per Plan 03-04. Page only invokes services and routes their mapped AuthError. Pitfall 7 grep. |
| T-03-enum-toast | Info Disclosure | Different toast text for "email sent" vs "email not found" | mitigate | D-09: single info toast `Se o email existir, o link de recuperação foi enviado.` fired regardless |
| T-03-recovery-flow-race | Logic bug | User lands on /auth/redefinir-senha while useRecoverySession is still 'validating' → form flashes | mitigate | Render 3 distinct states; the 'validating' state shows `<Loader2>` spinner (no form). 2-second timeout in hook falls back to 'invalid' — user never gets stuck |
| T-03-obsolete-import-orphans | Logic bug | After deleting 5 services, some page/hook still imports them → build fails | mitigate | Task 3 does a pre-delete grep + fixes every consumer before deleting. If any consumer can't be fixed in Phase 3 scope, DOCUMENT + defer (do NOT delete). |
