> **Pre-populated almost entirely from upstream.** No new design questions were asked — CONTEXT.md locked all 4 grey areas ("aceitar tudo"), and the design system (tokens, glass shell, shadcn primitives) is mature and in active use. Sources are noted inline.

## Spacing Scale

Declared values (multiples of 4 — matches the `--spacing-*` tokens already in `globals.css`):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gap, badge inner padding, checkbox-to-label |
| sm | 8px | Compact cell padding, gap between action-bar items |
| md | 16px | Default element spacing, card/glass inner padding rows, filter-bar gaps (`gap-4`) |
| lg | 24px | Section padding inside glass panels (`p-6`), header-to-table gap (`space-y-6`) |
| xl | 32px | Page vertical rhythm (`py-8`), major block separation |
| 2xl | 48px | Empty-state vertical padding (`p-12`) |
| 3xl | 64px | Reserved — page-level only; not expected this phase |

**Table density (dense table per CONTEXT.md, scannable for 30+ rows):**
- Row vertical padding: **8px** (`py-2`) — denser than the default shadcn `p-4`, which is correct for a 20-row/page scan grid. Header cells `py-2` as well.
- Horizontal cell padding: **16px** (`px-4`).
- Row min-height: **44px** (touch/click target floor; this is the **only spacing exception** — it is a minimum, not a scale value).

**Comparativo table:**
- Cell padding: **16px** (`p-4`) — comparativo is read-heavy, not scan-heavy, so cells are roomier than the panel.
- Column min-width: **200px** per candidate column (keeps justificativa_ia legible before horizontal scroll triggers).
- Sticky attribute (first) column width: **160px**.

Exceptions: table row **min-height 44px** (click-target floor, not a scale token). Everything else is on the 4px scale.

## Typography

Sizes pulled from the locked `--text-*` scale in `globals.css`. This phase declares **4 sizes** and **2 weights** (regular 400 + semibold 600). The legacy `font-bold` (700) on the page `<h1>` is retained from the canonical page for the page title only and is not a third weight in the new contract surface — see note.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / table cell | 14px (`text-sm`) | 400 (`font-normal`) | 1.5 |
| Label / badge / column header | 12px (`text-xs`) | 600 (`font-semibold`) | 1.4 |
| Section heading (panel/comparativo title) | 20px (`text-xl`) | 600 (`font-semibold`) | 1.2 |
| Score number (in score cell + comparativo score row) | 24px (`text-2xl`) | 600 (`font-semibold`) | 1.2 |

**Weight rule:** exactly two weights in the new contract surface — **400 (regular)** for all body/cell text and **600 (semibold)** for labels, headings, score numbers, and the AI badge. Do **not** introduce `font-bold` (700) or `font-medium` (500) in new Phase-10 components. The existing page `<h1 className="text-3xl font-bold">` from the canonical page may remain unchanged (it is pre-existing shell chrome), but new headings use `text-xl font-semibold`.

**Table cells are 14px, not 16px:** dense RH grid intentionally uses `text-sm` for scan-density across 30+ candidates. Justificativa_ia and gap/forte body copy in the comparativo also render at 14px.

## Color

The RH shell renders white-on-darkBlue glass (`Glass variant="white"` over `BackgroundImage darkBlue`). Inside the dense table the convention shifts: the table sits in a `Glass variant="white"` panel, but **score color bands** are the one place where qualitative semantic color is allowed to carry meaning.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#00109E` darkBlue background (`BackgroundImage darkBlue`) + `bg-white/15` glass surfaces | Page background, glass panels, table container, sidebar/topbar shell |
| Secondary (30%) | `white/10`–`white/25` translucent layers + `--neutral-*` text-on-glass (`text-white`, `text-white/80`, `text-white/60`) | Card/panel fills, filter bar, table header row (`bg-white/10`), row hover (`hover:bg-white/10`), muted metadata |
| Accent (10%) | `#35BFAD` brand-accent (`--accent`) | **See reserved-for list below** |
| Destructive | `#EF4444` (`--destructive`) | **Rejeitar** action button + its confirm dialog only |

**Accent (`#35BFAD`) reserved for — explicit list (never "all interactive elements"):**
1. The primary CTA **"Comparar (N)"** button in the sticky action bar (enabled state).
2. The **"Sugestão da IA — decisão é sempre humana"** badge accent/border (the `Sparkles` icon + badge border tint).
3. The selected-row left indicator / checkbox checked state.
4. The **"Avançar candidato"** primary action in the comparativo (advance = positive, gets accent; reject = destructive red).
5. The **"Exportar PDF"** button (secondary-weight accent outline, not filled).

Everything else (filters, search, pagination, secondary buttons, Ver Perfil) uses the neutral `Glass variant="white"` treatment — **no accent**.

**Score color bands (qualitative, the meaning-carrying exception per CONTEXT.md + RNF-07a):**

| Band | Score range | Token | Visual |
|------|-------------|-------|--------|
| Verde (forte) | 70–100 | `--semantic-success #10B981` | `bg-green-500/20 text-green-300 border-green-500/30` (on glass) |
| Amarelo (médio) | 40–69 | `--semantic-warning #F59E0B` | `bg-yellow-500/20 text-yellow-200 border-yellow-500/30` |
| Vermelho (fraco) | 0–39 | `--semantic-error #EF4444` | `bg-red-500/20 text-red-300 border-red-500/30` |
| Sem análise | null (pendente/falhou) | `--neutral-500 #A5A7A9` | `bg-white/10 text-white/50 border-white/20` + "—" |

The score band is a **chip showing the number 0-100 plus the color**, never a bare colored dot — the number must always be readable (accessibility + RNF-07a: color is a hint, the number is the signal). No auto-action is ever attached to a band (CONTEXT.md guardrail).

**Flags** render as `Badge` with neutral informative styling (`bg-white/10 text-white/70 border-white/20`) — **never** red/green, because flags are informative only and must not read as gating signals (CONTEXT.md: "sem comportamento de gating").

## Component Contracts

### A. Painel de Candidatos — dense table (`/rh/vagas/:id/candidatos`)

Replaces the current glass-cards list in `VagaCandidatosRHPage.tsx`, keeping the RHLayout/glass shell, header block, and filter bar. Table sits inside a `Glass variant="white" blur="lg"` panel.

**Column set (left → right):**

| # | Column | Width | Content | Sort |
|---|--------|-------|---------|------|
| 1 | Checkbox | 44px | Row select (`checkbox.tsx`); header = none (select-all is **not** offered — selection is capped at 10) | — |
| 2 | Candidato | flex | Avatar initial (40px gradient circle) + `nome_completo` (14px) | — |
| 3 | Score IA | 96px | Score band chip (number + color) + inline `Sparkles` micro-icon | **default DESC** |
| 4 | Top fortes | flex (max 2 lines) | Up to 2 `pontos_fortes` as muted text, truncated | — |
| 5 | Top gaps | flex (max 2 lines) | Up to 2 `gaps` as muted text, truncated | — |
| 6 | Etapa | 120px | `etapa_atual` badge | — |
| 7 | Status | 130px | Status badge (reuse `STATUS_LABELS`/`STATUS_COLORS`) | filter |
| 8 | Aplicou em | 120px | `data_candidatura` (`d 'de' MMM` ptBR) | — |
| 9 | Ações | 100px | **"Ver Perfil"** — icon (`Eye`) **+ visible text label** on desktop, neutral glass (`aria-label="Ver perfil"`) | — |

**Ordering rule (CONTEXT.md):** default `score_match DESC`. Candidaturas with **no analysis** (`status='pendente'` or `'falhou'`, score null) sort to the **end**, regardless of direction.

**Multi-select + sticky compare bar:**
- Selecting any row reveals a **sticky action bar** pinned to the bottom of the table panel (`Glass variant="white"`, `sticky bottom-0`).
- Bar shows: **"N de 10 selecionados"** count + **"Comparar (N)"** accent CTA + a "Limpar seleção" text button.
- **"Comparar" enabled only for 2–10 selections.** Below 2 → disabled with tooltip *"Selecione ao menos 2 candidatos para comparar."* At 10 → further checkboxes disabled with tooltip *"Máximo de 10 candidatos por comparativo."*

**Pagination:** server-side numbered, **20/page**, using `pagination.tsx` (prev / numbered pages / next). Reuses `PaginationParams` in `useCandidaturas`. Positioned below the table, right-aligned, inside the glass panel.

**Filters (retained from canonical page, restyled into a single filter bar):** etapa `Select` + status `Select` + name search `Input` (debounced). Glass-on-darkBlue styling (`bg-white/10 border-white/20 text-white`), matching the existing filter treatment.

**Per-row states:**
- **`pendente` (análise em andamento):** Score cell shows a `skeleton.tsx` shimmer chip + muted "Analisando…" label; row is selectable but excluded from default-sort ranking (sorts to end).
- **`falhou`:** Score cell shows "— Falhou" in the neutral band + a `RefreshCw` icon **+ visible "Reprocessar análise" text label** (verb+noun; `aria-label="Reprocessar análise"`) — never tooltip-only (CONTEXT.md: manual reprocess, never a missing row). Tooltip reinforces: *"A análise da IA falhou. Reprocessar análise."*

### B. Comparativo screen — candidates as columns

On-demand screen reached from the "Comparar (N)" CTA. Candidates are **columns** (up to 10), attributes are **rows**. Lives in a `Glass variant="white"` panel inside RHLayout. Horizontal scroll on overflow; the **first column (attribute labels) is sticky** (`sticky left-0`) so labels stay visible while scrolling candidate columns.

**Row set (top → bottom), attribute column sticky-left:**

| Row | Content |
|-----|---------|
| Header | Candidate name + avatar initial; ranking medal badge (1º, 2º, …) from IA ranking |
| Ranking IA | `1` … `N` (the **"Sugestão da IA"** badge appears once at the top of this row, not per-cell) |
| Score IA | Stable score band chip (number + color) — same band rules as the panel |
| Pontos fortes | Bulleted `pontos_fortes`, 14px |
| Gaps | Bulleted `gaps`, 14px |
| Justificativa IA | Relative justification text (14px, line-height 1.5), min column width 200px keeps it legible |
| Flags | Informative neutral badges (no gating color) |
| Ação | Inline **Avançar** (accent) + **Rejeitar** (destructive) buttons per candidate column |

**AI framing (RNF-07a — non-negotiable):** the **"Sugestão da IA — decisão é sempre humana"** badge is rendered prominently **once** at the top of the comparativo (header band) and **once** in the panel near the Score IA column header — it must be visible without scrolling on both surfaces. Ranking and score are explicitly framed as suggestions.

**Inline Avançar / Rejeitar (CONTEXT.md):** each calls the existing `avancar_etapa` RPC flow via a confirm dialog (`alert-dialog.tsx`).
- **Avançar:** confirm dialog *"Avançar {nome} para a próxima etapa?"* → primary accent confirm.
- **Rejeitar:** confirm dialog with **destructive** confirm. **No long justification required here** (CONTEXT.md — justification is mandatory only at Decisão Final / Etapa 6). Optional short note field, not required.

**Export PDF button + states:**
- **Idle:** **"Exportar PDF"** accent-outline button with `Download` icon, top-right of the comparativo panel.
- **Generating:** disabled + spinner + *"Gerando PDF…"* (jspdf runs client-side, near-instant; still show the transient state).
- **Done:** browser triggers download; ephemeral toast (`sonner.tsx`) *"PDF exportado."*
- **Error:** toast *"Não foi possível gerar o PDF. Tente novamente."*

### C. Shared "Sugestão da IA" badge (reused Phases 11-15)

A **shared component** (CONTEXT.md "specifics" — reused across the funnel). Contract:
- `Badge` with `Sparkles` icon (lucide), accent border tint (`border-[#35BFAD]/40 bg-[#35BFAD]/10 text-white`).
- Text: **"Sugestão da IA — decisão é sempre humana"** (12px, `font-semibold`, line-height 1.4).
- Compact variant (icon + "Sugestão da IA" only) for inline column-header use; full variant for panel/screen headers.
- Purely informative; never wraps an action; never carries a score color.

## Responsive / Desktop-First Behavior

RH surface is **desktop-first** (internal tool). No mobile layout commitment required this phase.

- **Panel table:** designed for ≥1024px. Below `lg`, the table becomes horizontally scrollable inside its glass panel (`overflow-x-auto`) rather than collapsing to cards — RH users are on desktop. The sticky compare bar stays pinned to the bottom of the viewport panel.
- **Comparativo:** horizontal scroll is the primary affordance by design (up to 10 columns). Sticky first column (`sticky left-0 z-10`) keeps attribute labels visible. No stacked/mobile reflow.
- **Filter bar:** `grid-cols-1 md:grid-cols-2 lg:grid-cols-5` (matches the canonical page's existing responsive grid).
- Touch targets: 44px row min-height and 40px+ buttons preserved for trackpad/click precision.
