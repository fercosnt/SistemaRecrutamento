**`BUCKET_CURRICULOS`** e **`TTL_CURRICULO_SEGUNDOS = 60`** como constantes nomeadas exportadas. O
comentário do TTL cita `get-curriculo-url/index.ts:206` como a duração canônica de URL assinada sobre

**`CURRICULOS_ALLOWLIST`** — a string passada a `.select(...)`, com **exatamente** o id da
candidatura, o caminho do currículo, a data de envio e o embed da vaga trazendo **só** o título. Nada
além disso entra: cada coluna a mais é payload que atravessa a rede e senta no cache do React Query
mesmo sem nunca ser renderizada — a lição literal do comentário T-08-09 de `candidaturasService.ts`.

**`listarMeusCurriculos(candidatoId): Promise<LinhaCurriculo[]>`** — `.from('candidaturas')` com a
allowlist, `.eq('candidato_id', candidatoId)`, filtro de currículo presente (`.not(...)`, no idioma
vivo de `obterGuardaCurriculo`), `.order('created_at', { ascending: false })`. Erro → o tradutor
privado, nunca a mensagem crua.

⚠ **Esta leitura NÃO esconde candidatura removida de forma suave, e isso é decisão, não descuido.**
O executor vai encontrar o predicado oposto em `get-curriculo-url/index.ts:164` (WR-03) e a tentação
de "corrigir" copiando-o é alta. **Não copie.** O WR-03 impede que um RH veja o CV de uma candidatura
removida — um fato entre pessoas diferentes. Aqui o leitor é o **dono do arquivo**, o arquivo
continua no Storage porque nenhuma rotina apaga dado de candidato hoje, e negar-lhe a existência de
um arquivo que a empresa guarda é a mentira oposta à que este milestone existe para corrigir. A razão
já está escrita, verbatim, no docblock de `obterGuardaCurriculo` (`privacidadeService.ts:212-220`) —
cite-a.

**`LinhaCurriculo`** — `{ id, caminho, enviadoEm, vagaTitulo: string | null }`. A normalização é do
serviço, não do componente: o embed de relação um-para-um do PostgREST chega ora como objeto, ora
como lista de um elemento conforme a tipagem gerada, e um componente que conheça as duas formas é um
componente que vai renderizar `[object Object]` no dia em que a tipagem mudar. Normalização
defensiva num lugar só (precedente 42-11).

**`mintarUrlCurriculoProprio(caminho: string): Promise<string>`** —
`supabase.storage.from(BUCKET_CURRICULOS).createSignedUrl(caminho, TTL_CURRICULO_SEGUNDOS)`. Erro, ou
resposta sem URL assinada, → `ExportacaoError` com a copy da linha; o erro cru fica fora da interface.

Nunca id de candidatura, nunca parâmetro de rota, nunca entrada de usuário. Escreva isso no docblock:
