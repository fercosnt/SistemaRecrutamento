### F-04-08-A — CSS bug: classes Tailwind inexistentes em FormularioCandidaturaPage.tsx (BLOCKER)

**Severidade:** P1 — bloqueia o fluxo end-to-end do candidato.
**Origem:** introduzido pelo Plan 04-07 (rewrite full single-page RHF).
**Arquivo afetado:** `src/components/pages/FormularioCandidaturaPage.tsx` (1 arquivo, 10 linhas).
**Sintoma:** botão "Enviar candidatura" invisível (branco em fundo branco), inputs sem
focus border, badge da vaga sem fundo, ícones sem cor.

**Causa raiz:** o arquivo usa classes da escala numérica do Tailwind (`primary-100`,
`primary-700`, `primary-800`) mas o `tailwind.config` deste projeto define apenas
`primary.DEFAULT` + `primary.foreground` (sem escala 50–950). Resultado: Tailwind
não gera CSS para essas classes (`@layer utilities` ignora) → estilo silenciosamente
ausente. Não dispara erro no console nem no build.

**Classes inválidas encontradas:**

| Classe inválida | Substituir por |
|---|---|
| `bg-primary-700` | `bg-primary` |
| `hover:bg-primary-800` | `hover:bg-primary/90` |
| `text-primary-700` | `text-primary` |
| `text-primary-800` | `text-primary` |
| `bg-primary-100` | `bg-primary/10` |
| `focus:border-primary-700` | `focus:border-primary` |

**Linhas em FormularioCandidaturaPage.tsx:** 405, 418, 462, 490, 536, 601, 616, 632, 664, 699.

**Evidência (Elements panel inspeção):**
```html
<button type="submit"
  class="w-full inline-flex items-center justify-center rounded-md bg-primary-700
  px-6 py-3 text-white font-semibold hover:bg-primary-800 disabled:opacity-50
  disabled:cursor-not-allowed transition-colors">
  <svg ...lucide-send.../>Enviar candidatura
</button>
```
Computed style: background-color = transparent (classe `bg-primary-700` não resolve).

**Escopo verificado:** apenas FormularioCandidaturaPage.tsx. Plans 04-06 (VagaDetalhe)
+ VagasPublicasPage + VagaLP + VagasRH + VagaCandidatos NÃO usam essa escala — todos
usam `bg-primary` + tokens shadcn corretamente. Bug é local ao Plan 04-07.

**Carryover plan:** ver `04-08-CARRYOVER-PLAN.md` Task 1.

### F-04-08-B — Vaga soft-deleted com status='ativa' (data hygiene, não-bloqueante)

**Carryover:** Phase 5 backlog — adicionar CHECK constraint `(status='ativa') ⇒ (deleted_at IS NULL)`
