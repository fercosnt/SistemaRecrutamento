<objective>
Remove the service_role key from the client-side bundle, delete supabaseAdmin, and clean up manual Lembrar-me session hacks from login pages.

Purpose: This is the highest-priority security fix -- the service_role key is currently bundled into the browser JS via VITE_SUPABASE_SERVICE_ROLE_KEY, giving any visitor full database access. Removing it has the smallest blast radius and must happen first.

Output: A client.ts that only exports the anon Supabase client, a cadastroService.ts that calls Edge Function instead of supabaseAdmin, and login pages without manual session persistence hacks.
</objective>
